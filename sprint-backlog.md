# Sprint Backlog — Book Swap SA

**Module:** PRP372S — Project Presentation 3  
**Project:** Book Swap SA — Second-Hand Textbook Swap  
**Tool used:** Trello

## 1. Introduction

The Sprint Backlog organises the work planned for Book Swap SA into smaller, manageable tasks. Our Trello board divides the project into seven sprints covering project initiation, business planning, system analysis and design, UI/UX design, core system development, testing and quality assurance, and project finalisation.

The sprint tasks help the team track progress, coordinate responsibilities and work towards completing the project.

## 2. Sprint Plan

| Sprint | Focus | Planned work |
|---|---|---|
| Sprint 1 | Project Initiation | Develop the problem statement, identify stakeholders, conduct market research, analyse competitors, complete a SWOT analysis, define the target market and develop the value proposition. |
| Sprint 2 | Business Plan Development | Develop the mission and vision statement, define business goals and objectives, develop the business model and marketing strategy, prepare the operational and financial plans, conduct risk analysis and complete the executive summary. |
| Sprint 3 | System Analysis and Design | Gather functional and non-functional requirements, create user stories, design the system architecture and database structure, create the Entity Relationship Diagram (ERD), develop use case diagrams and design wireframes. |
| Sprint 4 | UI/UX Design and Prototype Development | Design the home page, user registration page, user dashboard, textbook listings page, search and filter interface, and messaging interface. Review the prototype and finalise the UI design. |
| Sprint 5 | Core System Development | Develop user registration, user login, user profile management, textbook listings, search and filter functionality, and buyer-seller messaging. Integrate the front end with the back end and review development progress. |
| Sprint 6 | Testing and Quality Assurance | Test user registration, login, textbook listings, search and filter functionality, and buyer-seller messaging. Fix bugs, improve performance and conduct User Acceptance Testing (UAT). |
| Sprint 7 | Project Finalisation and Submission | Complete the technical documentation, complete the user manual, review the entire system, prepare the final presentation, prepare the live demonstration, conduct the final project review and submit the project. |

## 3. Task Allocation and Progress Tracking

Trello is used to organise the project tasks and show team participation. The board displays task cards, assigned team members and checklist progress. This makes it easier to monitor work and identify outstanding tasks.

The team can use the board to review progress, coordinate activities and identify work that still needs attention.
